# 💰 Meus Gastos — Aplicação de Gerenciamento Financeiro Pessoal

> Aplicação web leve e responsiva para controle de finanças pessoais, permitindo acompanhar saldo, receitas, despesas e organização por categorias em tempo real.

🔗 **Acesse a aplicação:** [Meus Gastos no GitHub Pages](https://toliveira-08.github.io/Trabalho-Desenvolvimento-H-brido/)

## 📌 Sobre o Projeto

O **Meus Gastos** foi desenvolvido como parte da disciplina de **Desenvolvimento Híbrido**. O objetivo principal é fornecer uma ferramenta intuitiva para que o usuário possa gerenciar seu orçamento pessoal com facilidade, registrando movimentações e acompanhando a evolução financeira do mês através de dados e relatórios visuais.

---

## Funcionalidades Principais

- **🔑 Autenticação de Usuários:** Login, cadastro com confirmação de senha e funcionalidade de recuperação de acesso ("Esqueci a senha").
- **📊 Dashboard Financeiro:**
  - Visualização resumida do **Saldo do Mês**.
  - Totalizadores dinâmicos de **Receitas** e **Despesas**.
- ** Lançamentos Financeiros:**
  - Formulário para registro rápido de novos ganhos ou gastos.
  - Histórico listado dos lançamentos do mês vigente.
- **🏷️ Gestão por Categorias:**
  - Criação e gerenciamento de categorias personalizadas.
  - Visualização de despesas agrupadas por categoria.

---

## 🛠️ Tecnologias Utilizadas

- **Front-end:** HTML5 (semântica e acessibilidade), CSS3 (estilização e layout responsivo) e JavaScript ES6+ (`script.js`).
- **Back-end & Banco de Dados:** [Firebase Authentication](https://firebase.google.com/docs/auth) e [Cloud Firestore](https://firebase.google.com/docs/firestore) para persistência em tempo real.
- **Hospedagem & Deploy:** GitHub Pages.
